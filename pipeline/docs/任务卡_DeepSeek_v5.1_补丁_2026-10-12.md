## 1. 代码改动一：保脸约束分级（step_plan）

在现有保脸逻辑前加分级判断（伪代码，按你们实际变量名落地）：

```
if fh <= H7 - 2m:                    # 一级：完整保脸（现行逻辑不变）
    lo, hi = fy - m, fy + fh + m
else:                                 # 二级：核心区保脸（巨脸特写）
    core_top = fy + 0.18 * fh         # 眉上方，允许裁发际线
    core_bot = fy + 0.92 * fh         # 下巴下缘，允许裁少量下巴
    core_h  = core_bot - core_top     # ≈ 0.74 * fh
    if core_h + 2m + TRAVEL <= H7:
        lo, hi = core_top - m, core_bot + m
    else:                             # 三级兜底：缩小 s（窗口变大，画面更全）
        H7_need = core_h + 2m + TRAVEL
        s_new  = 1080 / H7_need
        s_new  = max(s_new, 0.70)     # 下限防画面过小
        # 用 s_new 重算 H7，再走二级
```

**窗口摆放规则（二级/三级生效时）**：眼线（≈ fy + 0.35*fh）落在窗口显示高度的
33–40% 处（对标片巨脸特写取景：眼睛在上三分之一线，非居中）。

**错窗规则补充**：同句块拆出的子镜窗心错开量维持现有 use_cnt 逻辑，但巨脸镜（二级/三级
路径）错开量下限 = 0.5 × TRAVEL（≥72px），保证相邻子镜运动可辨；空间不足时错窗步长
按 0.5H → 0.3H → 0.15H 递减，禁止退化为中心静止。

**静止兜底改为显式报警**：若走完三级后 travel 仍 < 60px，该镜不再静默 fallback 中心——
标 `static=true` + status 强制 `choice`，进人工裁决回路。（v5 的教训：fallback 中心
静止会无声通过，到验收才发现。）
