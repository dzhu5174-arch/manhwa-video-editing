## 1. 四处代码改动（只许动 pipeline.py 的这四处）

### 1.1 拆镜阈值：SPLIT_SHOT_DUR 7.5 → 4.0
- 位置：pipeline.py 常量区。
- 语义：时间轴合并后的句块时长 > 4.0s 即拆为两镜（各约一半时长，吸附 VO 句内自然断点，
  无断点就对半切）。
- 预期：58 镜 → **78±5 镜**（口播句长中位 ~3.7s，超过一半的句块会被拆）。
- **拆出的两镜继承同一切片号 + 自动错窗**（沿用 plan0 现成的 use_cnt 错窗逻辑：窗口上下
  错开 ±0.5H），禁止给拆出镜换图或新建切片引用。

### 2.2 shot_map 从「镜层」上移到「句层」
- 现状：shot_map 键 = 最终镜号（与句块 1:1，58 条）。
- 改动：build_plan0 读取 shot_map 时，键重新解释为**合并句块 ID**（就是现在 58 条键的语义，
  内容不变）；拆镜产生的子镜通过父句块查切片号。
- **shot_map 的 58 条映射内容一条都不许改**（人工排定的语义分镜，是唯一不可再生的资产）。
- 硬校验：句块数 ≠ len(shot_map) 直接拒跑（沿用现有防错位机制，口径从镜数改为句块数）。

### 1.3 交替相位：demo 后重起
- 现状：方向按镜号奇偶（i%2），demo 覆盖会打断链条，导致其后连续同向（对账实测：
  剔除 demo 后余链交替率 86%，问题集中在三段连同向）。
- 改动：build_plan0 的方向分配逻辑——demo 覆盖镜保留 demo 自带方向；**demo 段结束后的
  第一镜重新起算奇偶相位**（即按「非 demo 镜序列」的索引交替，demo 镜不占相位索引）。
- 验收口径：对 plan.json 全部非 demo 镜按出现顺序算相邻交替率。

### 1.4 preview 按绝对时间铺帧（修 8.93s 累积漂移 bug）
- 现状：preview 把镜头无缝拼接，而 plan 的 t0/t1 是 whisper 句级绝对时间（句间有静音缝隙），
  两套时间轴到片尾累积偏差 8.93s——**v4 的「预览过目」对后半片实际上是无效的**。
- 改动：step_preview 铺帧改为按每镜 t0/t1 绝对时间放置，**缝隙处持上一镜末帧**；
  总时长 = 最后一句 t1（~225s），不再是镜头 dur 之和（~216s）。
- 这是 bug 修复，不是风格选择：修完后 preview 抽帧位置才能与 plan/剪映草稿一一对应。
