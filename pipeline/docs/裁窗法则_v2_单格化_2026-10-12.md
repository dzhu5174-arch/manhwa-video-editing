# 裁窗法则 v2 · 单格化裁剪（2026-10-12 晚 用户定律，**取代「全宽优先」**）

> 用户原话锚点：「保证画面不丢真，保证画面尽可能裁剪满，犹如将长条漫画裁剪为单格漫画」。
> 本文把用户的 5 组手裁示例转成机器可执行规格。**生效范围：build_plan0 裁窗 + QC 检查。**
> ⚠️ 规则演进：v2 紧特写铁律 →（10-12 早）全宽优先 s=0.8 → **（10-12 晚）单格化，本文为准**。
> 全宽优先的 s=0.8 铺宽策略在竖长切片上产生大块上下留白（用户实测差评），正式废弃。

---

## 一、法则（一句话版）

**每一镜 = 从长条上裁出的一格单格漫画：内容带居中充满 4:3 画幅，上下死重（纯白/气泡/
字幕框）出画，脸必须大；唯一例外是着重刻画的女性角色演出格，允许保留更完整上下文。**

## 三、算法规格（build_plan0 裁窗逻辑重写点）

### 3.1 内容图（每个切片先算三张掩码）
1. **白掩码**：亮度 >235 的连通域（泛白背景/空白带）；
2. **文字掩码**：气泡框 + 字幕框（现有 QC 的 text_cells/bubbles 检测 + 白斑轮廓）；
3. **脸掩码**：faces.json 脸框（**先重检**——当前 18 个切片 0 脸框，YuNet 阈值降到 0.4
   并加全尺寸重试，仍无脸的人工标注）。

### 3.2 内容带检测
- 逐行内容密度 = 1 −（白∪文字占比）；密度 >0.6 的连续行为「实内容行」；
- 内容带 = 最长实内容行区段（允许中间夹 ≤5% 高度的低密度缝）；一屏多格时取含脸/含
  主对话的带。

### 3.3 窗口与缩放（s 自适应，废弃 s=0.8 默认）
1. 候选窗口 = 4:3（原生 1080/s 高 × 1440/s 宽）；
2. **缩放由内容定**：若内容带为单人/脸部 → s 使主体脸高占显示画高 **30–60%**
   （脸高 native fh → s ≈ 0.30–0.60 × 1080/fh，clamp 0.7–2.2）；
   若为宽幅双人/群像带 → 保宽度满幅（s = 画布宽/带宽），纵向居中于人物带；
3. **硬约束（全部满足才合法）**：
   - 窗内白斑面积 ≤2%（逐帧可测，复用白斑普扫脚本）；
   - 窗内不含文字掩码的大块区域（气泡/字幕框中心不得在窗内）；
   - 含脸切片：脸必须完整在窗内（眼鼻嘴），脸高占比达标；
   - 窗口四边贴内容（上边行密度 >0.6、下边行密度 >0.6，即「上下比重极低」的机器判据）。
4. 无合法窗 → 换切片（交回 shot_map 语义层），**禁止 fallback 中心静默通过**。

### 3.4 同切片连续镜（阅读顺序连续性，修「窗口跳跶」）
- 同一切片的相邻镜窗口必须**按阅读顺序单调推进**（y 递增或递减，方向与叙事一致），
  禁止 >1 个窗高的随机跳变（现 s45→s46 跳 2500px、s62→s63 跳 11000px 这类全部禁止）；
- 拆分子镜：内容带内错窗 ±0.5H 照旧；
- demo 块：用户锁定窗维持，但建议按本法则复核一遍（尤其 c2_062 的 6% 覆盖率窗口）。

### 3.5 女性角色例外
- 识别：切片中女性角色脸 + 演出性构图（光环/全身立绘/情绪大格）→ 由语义层（shot_map
  制作时）显式标注 `fullbody_ok`，QC 对这类镜放宽 3.3-3 的白斑与占比约束，但白斑 ≤5%。

## 四、量化验收（QC 新增三项，全部可自动测）

| 指标 | 阈值 | 工具 |
|---|---|---|
| 窗内白斑面积 | ≤2%（女性演出格 ≤5%） | 白斑普扫脚本（已有，_外部证据\ep2_v5_终审） |
| 脸高占显示画高 | 30–60%（有脸镜 100% 达标） | faces.json × 窗口几何 |
| 窗口含脸率 | 目标 ≈ 基准（我方人工标注 59–69% 含脸） | 同上 |
| 窗口上/下边行内容密度 | >0.6 | 行密度剖面（新增，10 行代码） |
| 同切片相邻镜 y 跳变 | ≤1 个窗高且单调 | plan 序列检查（新增） |
