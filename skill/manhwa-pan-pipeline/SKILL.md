## 二、核心：运镜模型（这才是"丝滑且流水线稳定"的原因）

**一句话：每镜一次"线性匀速平移"，两个关键帧，线性插值；不是 S 型缓动。**

单镜实测（2.9s 上移镜）：
- 净位移 **-148 px**（1440×1080 尺度）
- **线性拟合残差 0.9 px（1%）** vs S 型缓动拟合残差 9.3 px（6%）→ **就是线性**
- 归一化轨迹：0 → -0.09 → -0.19 → -0.29 → -0.37 → -0.46 → -0.55 → -0.65 → -0.73 → -0.84 → -0.92（步长几乎恒定）

全片统计（31 个 ≥1s 的镜 + 2026-10-13 的 990 镜全量复核）：
| 项 | 值 |
|---|---|
| 速度 | 中位 **27.8 px/s**，p90 58.3，最大 68.4（1440×1080 尺度） |
| 行程 | **统一口径 = 画宽 10%（144px 显示）**（990 镜实测中位 9.9%，P25-75 8.5–14.2%；旧口径「12% 画幅高 ≈130px」废止） |
| 方向 | 纵移 82–97% / 横移 3–17%（横移=宽内容信号：信纸/并肩/侧脸横带）；**↓↑ 严格交替 ≥85%**（demo 覆盖镜后相位重起） |
| 缩放 | **无**（⚠ ECC/对数极坐标缩放测量不可信——小图噪声，SIFT 全尺寸复测 scale=1.0000） |
| 亚像素 | 每帧位移非整数 px（≈0.9 px/帧@1080）→ **亚像素渲染 = 丝滑感的来源** |

**裁窗执行（2026-10-13 新增）**：窗口不再管线内计算，由 `slice_bands.py` 产
`切片窗口方案.json`（切片级内容带 + 死重掩码 + 脸锚滑动打分），build_plan0 逐镜消费
（**来源核对：src=candidate，与候选集匹配率 100%**；禁止执行方自研裁窗逻辑）。

**为什么"流水线般稳定"**：参数只有 `{方向, 位移, 时长}` 三个，每镜线性走完、绝不加花活；位移量级固定（≈130px）；亚像素来自"高分辨率源 + 缩放输出"。人只审参数表，不改逐帧 → 天然一致。

**判定：是脚本/AE 式流程，不是手扣。** 依据：线性度 1%、位移量级高度一致、亚像素——手扣做不到这种一致性。

## 三、可执行复现（ffmpeg，路线 B）

```bash
# 每镜一个片段：线性平移（注意 y 是 t 的一次函数，不是 smoothstep）
ffmpeg -framerate 30 -loop 1 -i band.png -t {dur} \
  -vf "crop=w={W}:h={H}:x='{X0}':y='{Y0}+{DY}*(t/{dur})',scale=1080:1920:flags=lanczos,setsar=1" \
  -c:v libx264 -crf 18 -pix_fmt yuv420p -an seg.mp4
```
- `DY = 速度 × 时长`，速度取 **28–55 px/s（输出画幅尺度）**，上限 ≈0.25×画幅高
- 方向：纵向为主，横向约 1/3
- **不要加缓入缓出**（参考片是线性；若想"更高级"可加极轻的 5% 缓动，但别做成 S 型）
- 亚像素：从超清池（1800px）裁 → scale 到输出尺寸，天然亚像素 ✓

## 五、与项目现行规则的冲突（必须挑明）

| 项 | 项目旧规则 | 参考片实测 |
|---|---|---|
| 运镜曲线 | S 型缓入缓出 | **线性匀速** |
| 速度 | 60–90 px/s | 28–55 px/s（更慢） |
| 位移 | — | ≈0.12×画幅高，量级固定 |
| 每镜有脸 | 用户要求"保脸" | **不保证**（群像/场景也上） |

→ 两条都用：**要"参考片同款丝滑"就用线性**；要"高级感"用 S 型。速度取 30–60 px/s。

## 六、机器门禁（跑不过不许交付 · 2026-10-13 修订）

1. 每镜位移 >0（无静止镜）；**静止仅限环境空镜、全片 ≤2、人物镜静止强制 choice 报警**（禁止静默 fallback 中心）
2. 速度落在 25–70 px/s（输出画幅尺度）
3. 画面四边无白边/黑边；**窗内白斑面积 ≤2%**（女性演出格 fullbody_ok 放宽 5%）
4. 窗口内无纯白/纯黑空画面；**整页文字页/暗底文字帧（白连通域计数法）判死重，禁做镜**
5. 若该镜源图有脸 → 脸必须完整在画面内（含 ≥0.3×脸高的上下留白）；**脸高占画高 30–60%**
6. 分镜切点 = 客户 demo 的原切点（不许增删）；**同切片连续镜按阅读顺序单调推进（跳变 ≤1 窗高）**
7. **时间基准**：preview 按 t0/t1 绝对时间铺帧（缝隙持末帧）——防累计漂移（8.93s 事故）
8. **来源核对**：plan 每镜窗口须来自 切片窗口方案.json 候选集（src=candidate 匹配率 100%）
9. **交付流程**：15s demo（含 ≥2 个 face 窗切片 + 1 个暗底文字帧切片）先过四硬标准
   （缩放一致/无躯干/无重复构图/阅读顺序单调）+ face 窗 s 中位 ∈1.9–2.5 → 双终审 → 全片
